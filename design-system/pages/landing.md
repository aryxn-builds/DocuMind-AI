# Landing Page Design System Overrides

> **Context:** The public marketing website for DocuMind AI.

## Layout & Structure
- **Navigation:** Fixed top, highly transparent, minimal. Logo left, auth links right.
- **Hero:** Typography-driven. Massive `text-3xl` (or larger) heading. High contrast. No generic AI gradient or floating 3D objects.
- **Content Sections:** Use maximum `space-24` (96px) or even larger custom margins between sections for a spacious, editorial feel.
- **Product Preview:** Use a clean, bordered mockup of the application interface, showing the Document Workspace (PDF + Chat + Citations).

## Visuals
- **Graphics:** Restrained. Use abstract geometry (thin borders, subtle grid backgrounds) or literal product screenshots.
- **Contrast:** Utilize Stark black/white contrast for dramatic effect.

## Responsive
- **Mobile:** Collapse navigation into a hamburger menu. Stack product preview below hero text. Reduce horizontal padding.
