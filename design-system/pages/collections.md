# Collections Page Design System Overrides

> **Context:** The view for managing grouped documents (folders/collections).

## Layout
- Similar to the Documents page, utilizing a clean header and a grid/list view.

## Visuals
- **Collection Cards:** Simple, bordered cards (`--border-subtle`). Display the Collection Name, Document Count (in JetBrains Mono), and a small stacked-document icon (Lucide).
- **Empty State:** If a collection is empty, display a centered, minimal empty state. Icon (24px, `--text-muted`), brief explanation, and an `--accent-primary` button to "Add Documents".
